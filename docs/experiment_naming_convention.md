# Experiment Naming Convention

Generated by scripts/build_experiment_registry.py

Future experiment folders should use:

```text
<model>_u<universes>_top<top_n>_norm-<normalization>_h<hidden_dim>_l<num_layers>_gpool-<graph_pooling>_tpool-<temporal_pooling>_head-<head_type>_seed<seed>
```

## Required Fields

- model
- universes
- top_n
- normalization
- hidden_dim
- num_layers
- graph_pooling
- temporal_pooling
- head_type
- seed

## Optional Fields

- `k<k>` for graph-construction ablations
- `conv-graphsage` for Static GCN convolution variants
- `targetnorm` for target-normalization studies
- `summary` for summary-feature or hybrid studies
- `debug` or `diagnostic` prefix for non-final investigations

## Examples

```text
evolvegcn-h_u750_top1000_norm-none_h32_l2_gpool-mean_tpool-mean_head-linear_seed42
static-gcn_u750_top1000_norm-none_h32_l2_gpool-mean_tpool-final_head-mlp_seed42
summary-randomforest_u500_top500_norm-none_hna_lna_gpool-na_tpool-temporal_head-na_seed42
diagnostic_prediction-collapse_u750_top1000_norm-none_h32_l2_gpool-mean_tpool-mean_head-mlp_seed42
validation_raw-data_u750_top1000_norm-none_hna_lna_gpool-na_tpool-na_head-na_seedna
```

## Canonical ID Versus Folder Name

Existing experiment folders must not be renamed. The registry maps legacy names into
structured metadata and creates a canonical ID for comparison and reporting.

## Controlled Ablations

A controlled ablation should change one intended scientific variable at a time.
The dataset path, split IDs, model settings, optimizer settings, and seed set should
remain fixed except for the ablation variable.

## Seeds

Seeds are part of the experiment identity. Five-seed studies should normally use:

```text
42, 123, 777, 999, 2025
```

## Reproducibility

Dataset path and split IDs should be recorded in `config.json`, not only in the
folder name. Future configs should also save Git commit hash, dirty state,
command line, timestamp, and environment metadata.
