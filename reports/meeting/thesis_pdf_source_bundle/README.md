# Thesis PDF Source Bundle

This bundle contains verified source material for producing a professional
Bachelor Thesis experiment report.

## Included material

- Finalized controlled analysis packages
- Thesis and scientific summaries
- Presentation-ready summaries
- Main and supporting tables
- PNG figures
- Plot-data CSV files
- Analysis specifications
- Final verification reports
- Baseline and registry context when available
- Notebook 10 and its HTML/PDF exports when already generated

## Important

The bundle contains copied reporting artifacts only.

It does not contain or modify:

- graph datasets
- model checkpoints
- training logs
- raw experiment directories
- environment files

All scientific values should be traced to the included finalized analysis
packages and verification reports.
